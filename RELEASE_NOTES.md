## Текст для поля «Describe this release»

PersonGuard 2.0.0 — первый полноценный desktop-релиз локального менеджера паролей для Windows 11.

### Главное

- нативное WPF-приложение без WebView, аккаунта, сервера, телеметрии и сетевой синхронизации;
- переносимые зашифрованные сейфы `.pgd` с отдельным мастер-паролем для каждого файла;
- формат PGD2 с Argon2id, AES-256-GCM и проверкой целостности контейнера;
- безопасная смена мастер-пароля и миграция старых файлов PGD1 при сохранении;
- отдельный пароль приложения, Windows Hello и повторная авторизация перед доступом к секрету;
- поиск повторяющихся паролей с цветовой шкалой риска;
- группировка записей по email и интерактивная схема связей;
- вход через Apple, Google или Microsoft без хранения отдельного пароля;
- буфер обмена выключен по умолчанию и очищается через 20 секунд после разрешённого копирования;
- автоблокировка и защита окна от большинства стандартных средств захвата.

### Установка

Для обычной установки загрузите `PersonGuard-Setup.exe`. Установщик работает для текущего пользователя, не требует прав администратора и не требует отдельно устанавливать .NET.

Для запуска без установки загрузите `PersonGuard.exe`.

Поддерживаемая система: **Windows 11 x64**.

### Обновление с PGD1

PersonGuard открывает старые сейфы PGD1 и переводит их в PGD2 при следующем сохранении. Перед первым открытием рекомендуется сделать резервную копию исходного `.pgd`.

### Проверка загрузки

Загрузите соответствующий файл `.sha256` и сравните хеш в PowerShell:

```powershell
Get-FileHash .\PersonGuard-Setup.exe -Algorithm SHA256
Get-Content .\PersonGuard-Setup.exe.sha256
```

SHA-256 текущих подготовленных файлов:

```text
fbdc56788560fece67d994763422ef4ee97d8797b56ec718ca5ee0bc7ba4234b  PersonGuard-Setup.exe
dfab011e5f27ddf906ecd625f5b37f0407228cd04f5f6515644b0a332ff94116  PersonGuard.exe
```

### Важное о безопасности

Эта версия не проходила независимый аудит безопасности. Защита закрытого сейфа не может защитить секреты от вредоносной программы, которая уже работает с правами пользователя, администратора или ядра.

Автоматические проверки релизного исходного кода: **11/11 тестов пройдено**; официальный аудит NuGet не обнаружил зависимостей с известными уязвимостями на дату релиза.

**Текущие подготовленные `.exe` не подписаны Authenticode.** Windows может показать предупреждение SmartScreen. Проверяйте SHA-256 и загружайте файлы только со страницы этого репозитория. Если перед публикацией файлы будут подписаны или пересобраны, замените приведённые выше хеши и это предупреждение на фактические сведения о подписи.

У PersonGuard нет восстановления мастер-пароля. Храните отдельную резервную копию `.pgd` и не теряйте мастер-пароль.
